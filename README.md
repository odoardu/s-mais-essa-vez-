# É só mais essa vez.

Experiência literária com tipografia animada, trilha musical em loop e um vídeo final em moldura Polaroid.

## Executar localmente

Sirva esta pasta com `python3 -m http.server 8000` e abra `http://localhost:8000`.

## Interação

- Toque na frase inicial para começar.
- Toque na metade esquerda para voltar e na direita para avançar.
- Segure para pausar o texto; a música continua.

## Publicação

Projeto estático, sem dependências ou etapa de build. A configuração da Vercel está em `vercel.json`.

A música e o vídeo foram fornecidos pelo proprietário do projeto. Este repositório não concede licença de redistribuição desses materiais.
